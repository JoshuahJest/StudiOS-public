# Code Cascade Saver

An original, Apple-Silicon-native macOS screensaver inspired by the general 3D code-rain aesthetic. It does not reuse the proprietary Useless Creations executable or source code.

## Build

```bash
./build.sh
```

The script produces `dist/Code Cascade.saver` and installs a user-local copy at `~/Library/Screen Savers/Code Cascade.saver`.
